    Sync phone ↔ PC

    Your entries are saved on each device. To use the same data on your phone and PC, connect both to a private GitHub Gist (free). After that, changes sync automatically.
    1. On github.com → Settings → Tokens (classic), create a token with only the gist scope.
    2. Paste the same token here on every device and press Connect.

    Categories saves automatically

    The group tells Stats what each category is: Sleep and Waste get their own boxes, and People + Self count as free time.
